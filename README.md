# TanStack

The purpose of this app is to demonstrate the use of **TanStack Router**, **TanStack Query**, **TanStack Virtual**, **Headless UI** component library, and **Tailwind CSS**.

**/dist** contains files ready to be deployed to a web server,\
**/api** contains the server portion of the site, to be run using [Node.js](https://nodejs.org)

Uses [React](https://react.dev) as the main framework,\
[TanStack Router](https://tanstack.com/router/latest) for routing URLs and loader,\
[TanStack Query](https://tanstack.com/query/latest) for client side request caching,\
[TanStack Virtual](https://tanstack.com/virtual/latest) for virtualizing long lists,\
[MongoDB Atlas](https://cloud.mongodb.com) for database.\
[HeadlessUI](https://headlessui.com/) for some UI components like the toggle switch\
[Heroicons](https://heroicons.com/) for SVG icons.\
[TailwindCSS](https://tailwindcss.com/) for quick CSS prototyping

Compiled using [Vite](https://vite.dev) tool.
